# Music Popularity Capstone Project

Group: 4 

Genre: drum-and-bass 

Course: Machine Learning and AI internship, Thrive Campus

About

We are the data team at a music streaming service. Using Spotify audio features for tracks in one genre, we are  to answer three questions for the A&R department:

1. What makes a track popular? (regression)
2. Can we spot a hit before it charts? (classification)
3. What moods exist inside the genre? (clustering)

The analysis is in music_popularity_capstone.ipynb.

Data

Spotify Tracks Dataset from Kaggle: kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset. 


More sections (how to run, findings, limitations) will be added as the project progresses.
